# 📊 UPI Transactions Analysis Dashboard
An interactive **Microsoft Excel Data Analytics Project** to analyze UPI transactions, payment performance, cashback, bank-wise trends, and suspected fraud indicators.
## 📌 Project Overview
This project presents an interactive UPI Transactions Dashboard built using Microsoft Excel. It provides a comprehensive overview of digital payment activity through KPIs, charts, geographical analysis, and interactive filters.
The dashboard helps explore transaction patterns by UPI application, bank, state, transaction type, merchant, city, and time.
## 🎯 Project Objectives
- Analyze total transaction volume and transaction amount.
- Monitor transaction success rates and payment statuses.
- Compare UPI applications and bank performance.
- Analyze state-wise transaction amounts.
- Identify peak transaction hours and daily patterns.
- Review cashback and suspected fraud indicators.
- Explore transaction data using interactive filters.

## 📊 Dashboard Features
- **Daily Transaction Trends** — Track transaction amounts over time.
- **UPI App Analysis** — Compare PhonePe, Google Pay, Paytm, Amazon Pay, BHIM, and other applications.
- **Transaction Status** — Analyze successful, failed, pending, and refunded transactions.
- **State-wise Analysis** — Compare transaction amounts across Indian states.
- **Bank-wise Analysis** — Evaluate transaction amounts across banks.
- **Transaction Type Analysis** — Explore P2M, P2P, bill payments, online shopping, recharge, and other categories.
- **Hourly Analysis** — Identify periods of higher transaction activity.
- **Day & Hour Heatmap** — Explore transaction patterns by day and hour.
- **Interactive Filters** — Filter data by city, gender, merchant, and merchant category.
